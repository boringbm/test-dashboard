# Bootstrap React Login Form

A modern, responsive React JS login form built with Bootstrap 5 and custom CSS.

## Tech Stack
- **React 18**: For the frontend UI and state management.
- **Bootstrap 5**: For responsive, accessible UI components and styling.
- **Vite**: For fast development and building the project.
- **Custom CSS**: For additional styling and theming.

## Prerequisites
- Node.js (v18 or higher)
- npm (or yarn/pnpm)

## Installation

1. Clone the repository (if you are cloning it):
   ```bash
   git clone <repository-url>
   ```

2. Navigate into the project directory:
   ```bash
   cd bootstrap-login-form
   ```

3. Install the dependencies:
   ```bash
   npm install
   ```

## Running the Project

1. Start the development server:
   ```bash
   npm run dev
   ```

   The dev server will typically start at `http://localhost:5173`. Open this URL in your browser to see the login form.

## Building for Production

1. Build the project for production:
   ```bash
   npm run build
   ```

2. Preview the production build locally:
   ```bash
   npm run preview
   ```
